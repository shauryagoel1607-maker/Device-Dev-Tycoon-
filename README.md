# Device Dev Tycoon

A Godot 4 realistic electronics-company tycoon game.

## Inspiration

Gameplay inspiration drawn from **Devices Tycoon**. 3D city world direction inspired by **City Game Studio**. UI direction inspired by **Games Tycoon**. The project develops its own identity while learning from these predecessors.

## Scope & Products

Only plausible, real-world products are developed in-game:
- Smartphones
- Tablets
- Laptops
- Desktop PCs
- CPUs and GPUs

No fantasy, impossible, or non-realistic devices are included.

## Current Prototype Foundation

The prototype currently includes:
- Procedural 3D city with roads, buildings, headquarters, factory, and research lab
- Management tabs: Overview / Products / Research / Factory / Finance
- Product development and release systems
- Research and technology progression
- Factory capacity, efficiency, and staffing management
- Daily sales, revenue, costs, marketing, and loans

## Save System

JSON-based save and load functionality.

## Status

This is an **early prototype**. The project is unvalidated and has not been fully tested in Godot. It still needs iteration for balance, visuals, mobile controls, and performance.
